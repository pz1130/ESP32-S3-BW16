## BW16 侧引脚说明（RTL8720DN）

| 引脚 | Arduino 名 | 用途 |
|---|---|---|
| PA25 | D7 | **Serial1 TX → S3**（原 OLED SCL，已腾空） |
| PA26 | D8 | **Serial1 RX ← S3**（原 OLED SDA，已腾空） |
| PA7 / PA8 | D0 / D1 | 调试+烧录口（USB CH340），不要接 S3 |
| PA12/13/14 | D12/D11/D10 | 板载 RGB 灯（固件自用） |
| PA27 / PB3 | D2 / D6 | SWD 调试，避开 |

原理：BW16 的 Serial1（LP_UART）默认引脚 PB1/PB2 在板上连着 USB 芯片，
固件里已通过 `serial_api.h` 的 `serialApiRemapPins()` 在运行时把它重映射到 PA25/PA26。

## 首次上电调试清单

1. **只接 BW16 + USB**：串口监视器（COM3, 115200）应看到
   `串口控制模式：上电射频（不广播 AP）` 且不再出现 "WebUI AP模式启动成功"
2. **S3 单独上电**（未接 BW16）：串口监视器应看到 WiFi 连接和 IP；
   OLED 背光亮、显示状态页 "离线(检查接线)" —— 这是正常的（还没接串口线）
3. **接上两根串口线 + 共地**：S3 OLED 状态页变 "在线"；浏览器访问 S3 IP，
   状态页 BW16 显示在线
4. **扫描测试**：Web 点扫描 → 列表出现；OLED 扫描页按确认也能扫
5. **攻击测试**：选目标 → 启动 Deauth → BW16 板载红灯 0.5s 闪烁；
   停止后恢复蓝灯常亮

## 常见问题

| 现象 | 原因/解决 |
|---|---|
| S3 状态页显示 BW16 离线 | 串口线没接/没共地/TX RX 接反（对调试试） |
| OLED 花屏/不亮 | 1.3寸屏是 SH1106：config.h 里 `OLED_USE_SH1106` 改 1 |
| OLED 中文乱码 | 已用 wqy12 中文字体，确认没改掉 `enableUTF8Print()` |
| Web 打不开 | 手机/电脑必须连**家里 WiFi**（和 S3 同网）；看 S3 串口打印的 IP |
| 抓包下载 0 字节 | 先扫描→选中目标→开始抓包，等 handshake_status 的 captured=true 再下载 |
| 串口全是乱码 | 两板波特率不一致或没共地；确认 BW16 固件是 S3Bridge 版（开机日志有"串口控制模式"） |
| 串口线要不要串电阻 | 不需要（双 3.3V 推挽输出，115200 极慢）。可选保险：两根信号线各串 100~330Ω，防接错短路。OLED/按键也不用（模块自带上拉/固件内部上拉） |
