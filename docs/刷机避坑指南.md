# BW16 刷机避坑指南

> 基于 2026-09-29 完整刷机实战总结。固件：BW16-Tools Web UI Edition，板子：Ai-Thinker BW16-Kit (RTL8720DN, COM3/CH340)。

## 一、固件本身的坑

### 1. Release 的 bin ≠ 仓库最新代码
- **症状**：刷完官方 v3.0 release 的 bin，开机串口报 `Error: SSID can't be empty`，AP 起不来
- **原因**：v3.0 release（2025-10-12 构建）是旧代码，"开机自动开 WebUI 热点"只存在于 main 分支最后的工作区改动里（作者 2025-10-22 归档，从未发布过 bin）
- **教训**：想要某个行为，先确认 bin 里真的有（看串口横幅：旧版 `BW16 WiFi Deauther`，Web UI 版 `BW16-Tools v3.0 (Web UI Edition)`）；不行就得自己编译

### 2. 未提交的源码不能直接编译过
工作区里的 Web UI Edition 改动有 3 处编译错误，修复方法：
- `stopAllAttacks()` 定义了两次 → 合并成一份（保留新版状态清理 + 旧版 OLED 流程的标志位）
- `g_selectedAuthPage` 未声明 → 应为 `g_apSelectedPage`；钓鱼模板映射：`template=1`→`AP_WEB_ROUTER_AUTH`（路由器页面，web_auth2），`template=2`→`AP_WEB_TEST`（AP认证页，web_auth1）
- `sys_reset()` 未声明 → 文件头部加 `extern "C" void sys_reset(void);`

### 3. 必须用 Arduino 核心 3.1.7（README 强调 3 次感叹号）
- arduino-cli 装：`arduino-cli core install realtek:amebad@3.1.7`
- 3.1.9 能编译但**WiFiServer 的 startServer 签名变了**：针对 3.1.9 的 `BLOCKING_MODE` 修复在 3.1.7 上必须回退成 HEAD 原版写法
- 编译命令：`arduino-cli compile --fqbn realtek:AmebaD:Ai-Thinker_BW16 --build-path build_tmp BW16-Tools`
- 库依赖：仓库 `libraries/*.zip` 全部解压到 `Documents\Arduino\libraries\`

## 二、烧录的坑

### 4. 单个 bin 不是完整固件
- **症状**：不知道怎么烧那个 1.1MB 的 `BW16-Tools_V3.0.bin`
- **真相**：它只是应用镜像 `km0_km4_image2.bin`，烧到 **flash 0x6000**。还差两个引导分区：
  - `km0_boot_all.bin`（4500 字节）→ **0x0000**
  - `km4_boot_all.bin`（4456 字节）→ **0x4000**
  - 来源：ambiot/ambd_arduino 仓库 `Ameba_misc/Image_Releated/`（与工具包 `bsp/image/PMU_bins/NONE/` 逐字节一致）

### 5. 官方烧录工具的目录要求
- 工具：Arduino 板包里的 `ameba_d_tools_windows-1.1.3.tar.gz` 中的 `upload_image_tool_windows.exe`
- **必须把 `cygwin1.dll` 放它同目录**，否则报 `error while loading shared libraries`（exit 127）
- 工具从**当前工作目录**读这 4 个文件：`km0_boot_all.bin`、`km4_boot_all.bin`、`km0_km4_image2.bin`、`imgtool_flashloader_amebad.bin`
- 命令：`./upload_image_tool_windows.exe . COM3 BW16 0 0 115200 0`

### 6. 必须手动进下载模式（没有免按键的路）
- BW16 **没有** ESP 那种 DTR/RTS 自动下载电路（官方 boards.txt 明确 `auto_mode=Disable`），工具的自动模式必失败
- 姿势：**按住 Burn 2~3 秒 → 按住期间按一下 RST → 松开**
- 更稳的姿势：拔 USB → 按住 Burn → 插回 USB → 继续按 2 秒 → 松开
- 下载模式会保持几分钟，开个后台循环（每 15 秒重试）抓窗口最省心

### 7. 波特率用 115200
- 官方 BW16 板定义没写 upload.speed（即回退 115200）。写入 1.1MB 全程约 **4 分钟**，属正常

### 8. USB 线/口质量是隐形杀手
- **症状**：每次都能连上（同步是短促通讯），但写入到 4~18 分钟不完成/卡死（正常 4 分钟）；工具不报错只是干等
- **原因**：USB 链路扛不住持续大流量传输
- **解决**：换**主板后置** USB 口 + 好线；判断方法=看写入总时长是否回到 4 分钟
- 烧录工具没有写入超时，卡死要手动杀 `upload_image_tool_windows.exe` 进程再重试

### 9. 烧完板子停在下载模式，不会自己重启
- 每次烧完**必须按一下 RST** 新固件才会启动（只按 RST，不用 Burn）

## 三、固件运行的坑（无屏纯 Web 场景）

### 10. AP 信道漂移 → 手机卡"连接中"
- **症状**：热点能看到，密码正确但一直连不上
- **原因**：AP 启动后执行 WiFi 扫描，射频停在最后扫描的信道，而信标里还写着信道 1
- **解决**：每次扫描后执行 `wext_set_channel(WLAN0_NAME, WEB_UI_CHANNEL);` 拉回信道

### 11. 扫描不能放在 AP 启动之前
- **症状**：开机扫描报 `netif is DOWN` + `ioctl[RTKIOCSIWSCAN] error`，扫描结果为空
- **原因**：开机时 WiFi 还没初始化
- **正确顺序**：先 startWebUI() → 再 scanNetworks() → 立即拉回信道

### 12. 连上热点但拿不到 IP（网页打不开）——最大的坑
- **症状**：关联和 WPA2 握手都成功（串口有 `set pairwise key`），但客户端拿不到 IP，反复 `disassoc reason code(8)`
- **原因**：`WiFi.apbegin` 之前执行的 `resetWiFiModule()`（wifi_off/wifi_on）和 `disconnectWiFi()` 破坏了 LWIP/DHCP 服务端初始化
- **解决**：对齐官方 WiFiAPMode 示例——干净状态下直接 `apbegin`，**AP 启动前不做任何复位**
- **反面教训**：换成 SDK 的 `wifi_restart_ap()` 反而更糟（内部报 `Error!!!upd_new error`，AP 直接起不来）
- 验证方法：看电脑拿到的是不是 192.168.1.x（Windows 显示"已连接"但 DHCP 失败时会悄悄退回原来的 WiFi）

### 13. PC 的 WiFi 扫描永远扫不到 BW16-WebUI
- 手机能看到、PC 的 netsh 扫描看不到——**不能**用 PC 扫描判断 AP 死活，用手机或直接连

## 四、验证技巧

- 串口监听用 PowerShell `SerialPort`（115200），板子在下载模式时输出连续 `0x15`(NAK)，正常固件是 ASCII 日志
- 串口每秒 2 条 `[ERROR] Accept connection failed` 是核心非阻塞 accept 的固有刷屏，**无害**
- 串口三态速查：`0x15 连续流`＝还在下载模式；`横幅+启动日志`＝固件刚启动；`静默`＝固件稳定运行中

## 五、下次 10 分钟速查流程

```bash
# 1. 编译（如源码有改动）
arduino-cli compile --fqbn realtek:AmebaD:Ai-Thinker_BW16 --build-path build_tmp BW16-Tools
cp build_tmp/km0_km4_image2.bin flash_ws/

# 2. 烧录（flash_ws 目录下，含 cygwin1.dll）
cd flash_ws
#    循环重试版：
for i in $(seq 1 30); do
  out=$(timeout 600 ./upload_image_tool_windows.exe . COM3 BW16 0 0 115200 0 2>&1)
  echo "$out" | grep -q "sent successfully" && { echo SUCCESS; break; }
  sleep 2
done

# 3. 烧录中按住 Burn → 按 RST → 松开（循环会自动抓窗口）

# 4. 烧完按一下 RST，连 BW16-WebUI / 1234567890，开 http://192.168.1.1
```
